## Unreleased

- Новые языки интерфейса: упрощённый китайский (简体中文, предоставлен сообществом), французский, итальянский, испанский и русский. Выбираются в меню «Язык». Французский, итальянский, испанский и русский переведены с помощью ИИ и ещё не проверены носителями языка; исправления приветствуются в виде задачи Translation.
- Ещё не переведённые тексты отображаются на английском.
- Перевести приложение на другие языки теперь гораздо проще: см. TRANSLATING.md или откройте задачу Translation.
- Игровые термины (атрибуты, позиции, владение ногами, характеры, игровое время и другое) теперь соответствуют официальным текстам каждой языковой версии игры.
- Названия и сокращения ролей FM27 следуют языку интерфейса — так, как в этой языковой версии игры. Ваши тактики и настройки не меняются.
- Значения игроков так же следуют языку интерфейса: атрибуты, характер, владение ногами, ведущая нога и позиции.
- Денежные суммы можно показывать в фунтах, долларах США, евро, швейцарских франках, китайских юанях или российских рублях («Язык» → «Валюта»), пересчитанные по курсам самой игры. По умолчанию валюта соответствует языку интерфейса. Сохранённые значения не меняются.
- Для FM27 импорт теперь сначала предлагает сохранение игры. Экспорт HTML/CSV работает как прежде.
- Экспорт HTML/CSV читается на всех поддерживаемых языках игры (английский, немецкий, французский, итальянский, упрощённый китайский, русский, испанский). Язык определяется по заголовкам столбцов; его также можно задать в «Настройки» → «Импорт».
- Необязательная проверка обновлений, по умолчанию выключена: приложение один раз спрашивает, можно ли искать новые версии при запуске. Оно запрашивает у GitHub только последнюю версию и не отправляет данных о вас или ваших сохранениях.
- Новая версия показывается как подсказка с её изменениями и кнопкой загрузки, которая открывает страницу выпуска. Ничего не устанавливается автоматически; версию можно пропустить.
- «Настройки» → «Сохранения» → «Обновления»: включить или выключить проверку, учитывать тестовые версии или проверить сейчас.
- После обновления приложение один раз показывает новое — на языке интерфейса. «Больше не показывать» отключает это (также в «Настройки» → «Сохранения» → «Обновления»); «Справка» → «Что нового» показывает это в любое время. Подсказка об обновлении тоже показывает изменения новой версии на языке интерфейса.
- Лучший состав FM27: игрок может подменить на месте вне своих позиций в одной из двух расстановок, чтобы места больше не оставались пустыми только потому, что ни у кого нет обеих позиций. Его значение там снижается (коэффициент 0,80, «Настройки» → «Состав и анализ»); роль отображается заштрихованной.
- Игроки также оцениваются для ролей, которые им не назначены, если они нужны расстановке.
- Совмещённый вид: место, свободное и с мячом, и без мяча, показывается одной карточкой, а свободные места больше не рисуют соединительные линии.
