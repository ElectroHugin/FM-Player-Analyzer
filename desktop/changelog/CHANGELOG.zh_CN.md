## Unreleased

- 新增界面语言：简体中文（由社区贡献）、法语、意大利语、西班牙语和俄语。可在“语言”菜单中选择。法语、意大利语、西班牙语和俄语由 AI 工具翻译，尚未经母语者审校；欢迎以 Translation issue 提交更正。
- 尚未翻译的文本以英文显示。
- 现在将本应用翻译成更多语言要容易得多：参见 TRANSLATING.md 或提交 Translation issue。
- 游戏术语（属性、位置、逆足能力、性格、出场时间等）现在与各语言版本游戏的官方文本一致。
- FM27 角色名称和缩写跟随界面语言，用词与该语言版本的游戏相同。您的战术和设置保持不变。
- 球员数值同样跟随界面语言：属性、性格、逆足能力、惯用脚和位置。
- 金额可以英镑、美元、欧元、瑞士法郎、人民币或俄罗斯卢布显示（语言 → 货币），按游戏自身的汇率换算。默认货币与界面语言相符。已保存的数值保持不变。
- 对于 FM27，导入现在优先提供存档。HTML/CSV 导出仍可照常使用。
- HTML/CSV 导出可以用所有支持的游戏语言读取（英语、德语、法语、意大利语、简体中文、俄语、西班牙语）。语言根据列标题识别，也可在 设置 → 导入 中指定。
- 可选的更新检查，默认关闭：应用会询问一次是否可以在启动时查找新版本。它只向 GitHub 查询最新版本，不发送任何关于您或您存档的数据。
- 新版本会以提示的形式显示，附带更新内容和一个打开发布页面的下载按钮。不会自动安装任何内容；可以跳过某个版本。
- 设置 → 存档 → 更新：开启或关闭检查、包含测试版本或立即检查。
- 更新后，应用会以界面语言显示一次更新内容。“不再显示”可关闭此功能（也可在 设置 → 存档 → 更新 中设置）；帮助 → 更新内容 可随时查看。更新提示同样以界面语言显示新版本的更新内容。
- FM27 最佳阵容：在两套阵型之一中，球员可以在其位置之外的站位临时顶替，这样站位不会再仅因为没有人同时具备两个位置而空缺。他在该处的数值会降低（系数 0.80，设置 → 阵容与分析）；该角色以斜线显示。
- 当阵型需要时，球员也会针对未分配给他们的角色进行评估。
- 综合视图：持球和无球时都空缺的站位显示为一个方框，空缺站位不再绘制连接线。
