Public test build of 2.3.1. Not a final release.

**New: Simplified Chinese (简体中文)**, based on the translation contributed in #31. Choose it under *Language* (or the globe button on the start screen) and restart the app.

What to test:

- Do the texts read naturally? Are football terms the ones you know from Football Manager?
- Is any text cut off, overlapping or still in German?
- File dialogs (open save, import export) show the expected files.

Anything not translated yet appears in English. Feedback and corrections are welcome in #31 or via a Translation issue; see [TRANSLATING.md](https://github.com/ElectroHugin/FM-Player-Analyzer/blob/90da03f/desktop/translations/TRANSLATING.md) for how to help.

No database changes: saves stay compatible with 2.3.0. Backing up `%LOCALAPPDATA%\FM24PlayerAnalyzer` before installing is still a good idea.
